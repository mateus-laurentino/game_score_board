# 🃏 Card Game Score Tracker

Aplicativo mobile desenvolvido em **Flutter** para o controle e marcação de pontos em jogos de cartas e tabuleiros. Desenvolvido para eliminar o uso de papel e caneta, mantendo o histórico de partidas de forma prática e rápida.

## 🚀 Tecnologias Utilizadas

* **Flutter** & **Dart** (Frontend Multiplataforma)
* *Gerenciador de Estado* (ex: Provider / Riverpod / Bloc)
* *Armazenamento Local* (ex: Hive / SharedPreferences)

## 📱 Principais Funcionalidades

* **Placar Dinâmico:** Adição e remoção rápida de pontos por jogador ou equipe.
* **Histórico de Partidas:** Acompanhe o andamento dos rounds e veja quem está liderando a mesa.
* **Personalização de Regras:** Configuração de limites de pontuação, número de rodadas e nomes dos participantes.
* **Interface Intuitiva:** Layout otimizado para uso rápido direto na mesa de jogo.

## 🛠️ Como Executar o Projeto

1. Clone o repositório: `git clone [https://github.com/seu-usuario/card-game-scoreboard.git](https://github.com/seu-usuario/card-game-scoreboard.git)`
2. Instale as dependências: `flutter pub get`
3. Execute o aplicativo: `flutter run`
